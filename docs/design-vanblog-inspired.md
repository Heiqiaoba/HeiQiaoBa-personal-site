# 界面设计：借鉴 vanBlog 的设计语言

> 2026-11-26。参考资料：vanBlog（github.com/mereithhh/vanblog，GPL-3.0）。
> 只借鉴视觉布局与交互模式，不复制其源码；本项目保持 MIT 自由选择许可证。

## 从 vanBlog 提取的设计要素

1. **配色**：主题色 `#1772B4`（明青色），浅色侧边栏（`navTheme: light`），正文 `#374151`，次级文字 `rgb(107,114,128)`。
2. **后台布局**：左侧固定侧边栏 + 顶栏（48px）+ 内容区（`PageContainer` ghost 头部）。后台与前台视觉分离。
3. **仪表盘**：`数据概览 / 访客统计 / 文章分析` 三个 Tab；顶部 4 张统计卡（文章数 / 总字数 / 访客数 / 访问数），响应式拆分；下方趋势图。
4. **文章管理**：ProTable 表格 + 搜索 + 批量删除/导出 + 响应式列裁剪；顶部「写文章」按钮；草稿单独入口。
5. **编辑器**：独立全屏页面，标题/标签/路径字段 + Vditor 编辑器（Markdown/所见即所得）+ 保存提示 + Ctrl+S 快捷键 + 本地缓存草稿。
6. **前台**：浅色/深色双主题，衬线标题 + 无衬线正文，文章卡片、目录、标签、搜索、RSS。

## 本项目适配方案（React 18 + Ant Design 5，不用 Next.js/ProComponents）

- **主题**：antd `colorPrimary` 改为 `#1772B4`；CSS 变量 `--brand`、`--text` 等对齐上述色值。
- **写作台**：侧边栏导航（概览 / 文章 / 草稿）+ 统计卡（文章数/已发布/草稿/标签数）+ 文章表格（搜索/状态筛选/批量删除）。沿用现有 antd Table，但不引入 ProComponents。
- **编辑器**：全屏布局（顶部工具条 + 标题输入 + 左右分栏 Markdown/预览），Ctrl+S 保存提示，slug 自动生成，字数/阅读时间。
- **前台**：文章卡片网格、阅读友好的正文排版、标签筛选、深浅主题切换（跟随系统 + 手动）。
- **登录页**：居中卡片 + 品牌区，简洁留白。

## 渐进范围

本次按完整全站改造：前台（首页/列表/详情/项目/关于/登录）+ 写作台（概览/文章/草稿/编辑器）。
